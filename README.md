# NES-PO Management System (FM-PU-02 / Rev.00)
**บริษัท นวพล เอ็นจิเนียริ่ง แอนด์ ซัพพลาย จำกัด**

ระบบ Web Application สำหรับเปิดใบสั่งซื้อ (Purchase Order), ระบบอนุมัติออนไลน์พร้อมประทับลายเซ็นดิจิทัลอัตโนมัติลงในแบบฟอร์ม `FM-PU-02 / Rev.00`, ระบบฐานข้อมูลสินค้า (Items) & ผู้ขาย (Vendors), และระบบเปรียบเทียบราคาย้อนหลัง

## วิธีเปิดใช้งานระบบ
1. **เปิดผ่าน Browser ได้ทันที**: ระบบกำลังทำงานอยู่ที่ `http://localhost:3000`
2. **เปิดใช้งานในครั้งถัดไป**:
   - ดับเบิลคลิกไฟล์ `start_app.bat` หรือ
   - รันคำสั่ง `node server.js` (หรือ `npm start`) ในโฟลเดอร์โปรเจกต์
3. **รีเซ็ตฐานข้อมูลเริ่มต้นใหม่ (หากต้องการ)**:
   - รันคำสั่ง `python seed_db.py`

## โครงสร้างไฟล์หลัก
- `server.js` — Backend Server & REST API เชื่อมต่อฐานข้อมูล SQLite (`node:sqlite`)
- `seed_db.py` — สคริปต์นำเข้าและ Clean ข้อมูลจาก `nes_master_data.xlsx` สู่ `nes_po.db` (ผู้ขาย 411 ราย, หมวดหมู่ผู้ขาย 16 หมวด, สินค้า 928 รายการ, หมวดหมู่สินค้า 18 หมวด และใบสั่งซื้อตัวอย่าง `PO/NES/0062-2026`)
- `nes_po.db` — ฐานข้อมูล SQLite ของระบบ
- `public/index.html` — โครงสร้างหน้าเว็บแอปพลิเคชันและหน้าต่าง Modal
- `public/styles.css` — สไตล์หน้าจอและรูปแบบกระดาษ A4 ของใบสั่งซื้อ `FM-PU-02 / Rev.00` (`@media print`)
- `public/app.js` — ระบบคำนวณใบสั่งซื้อ, แปลงตัวเลขเป็นคำอ่านบาทไทย (`thaiBahtText`), Searchable Dropdown, ระบบอนุมัติ และกราฟเปรียบเทียบราคา
